# 数据结构与算法（C++实现）
> 基于 Visual Studio 编写，包含经典排序、查找、图论、并查集等基础算法源码，适合学习与复习。

## 📁 项目介绍
本仓库使用 C++ 实现常见的数据结构与基础算法，采用**头文件(.h) + 源文件(.cpp)** 的分离写法，部分模块附带独立测试文件。
可以直接用 Visual Studio 打开 `数据结构与算法.sln` 编译运行。

## 📚 算法清单
### 🔹 排序算法
- 冒泡排序 `bubble_sort`
- 插入排序 `insert_sort`
- 选择排序 `selection_sort`
- 希尔排序 `shell_sort`
- 归并排序 `merge_sort`
- 快速排序 `quick_sort`
- 堆排序 `heap`
- 计数排序 `count_sort`
- 桶排序 `bucket_sort`
- 基数排序 `radix_sort`

### 🔹 查找算法
- 二分查找 `binary_search`（附带独立测试文件 `binary_search_test.cpp`）

### 🔹 图论
- 图结构 `graph`，图测试代码 `GraphTest.cpp`

### 🔹 其他
- 并查集 `union_find`，配套测试 `union_find_test.cpp`
- 前缀和 `prefix_sum`

## 🛠 编译运行
1. 使用 Visual Studio 打开解决方案文件：`数据结构与算法.sln`
2. 直接编译运行，入口文件为 `main.cpp`
3. 部分算法模块有独立测试文件，可以修改项目入口单独调试。

## ✨ 特点
- 代码模块化，每个算法独立封装，便于单独阅读
- 基础算法完整覆盖，适合算法入门、期末复习、蓝桥杯等算法竞赛基础练习
- 纯C++基础语法，无第三方库依赖
